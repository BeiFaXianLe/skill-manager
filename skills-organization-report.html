04关键问题：符号链接静默失败

这是本次唯一的技术障碍，也是之前部署看似成功、实际全是空目录的原因

根因

CLI 默认用 symlink 模式部署。当前账户非管理员且未开启开发者模式，Windows 会拦截符号链接创建 —— 但拦截方式是静默降级，留下一个空目录，而 CLI 仍记录 mode: symlink, status: ok。命令行 ln -s 和 PowerShell New-Item -ItemType SymbolicLink 复现同样结果。

Junction 不受此限制，无需管理员权限。桌面版 Skills Manager 正是用 Junction，所以它管理的技能一直正常。

处理过程

STEP 1发现异常部署报 24/24 成功，抽查目录全为空
→
STEP 2定位根因dir /AL 确认 0 个重解析点，全是普通空目录
→
STEP 3验证替代Junction 创建成功且内容可读，CLI 也认可
→
STEP 4重建清空目录 + Junction 重建 27 个，再 deploy 补齐

最终 43/43 全部为 Junction 链接，抽查 SKILL.md 均可正常读取。后续 CLI 的 update 会直接作用于中央库，所有 agent 同步生效。docs / writing / diagram 三组在整理时又遇到过两次同样的空目录，均用 Junction 手工修好。
